## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user input → textarea → in-memory state | Untrusted free text the learner types |
| in-memory state → localStorage (fluentpath.celpip.v1) | Client-owned, user-modifiable persistence; no server crosses in this phase |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-01 | Tampering | localStorage read in celpip-progress.readLocal | medium | mitigate | Defensive JSON.parse in try/catch returning CELPIP_EMPTY; SSR guard on window — corrupted or hand-edited storage never crashes the app |
| T-01-02 | Information Disclosure | Rendering user text + model answer | medium | mitigate | All stored/user text rendered through JSX text interpolation only; no raw-HTML injection API used anywhere in celpip components |
| T-01-SC | Tampering | npm/pip/cargo installs | low | accept | No package installs this phase — CONTEXT.md locks "no new libraries"; nothing to audit |
