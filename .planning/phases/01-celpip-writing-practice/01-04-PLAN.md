## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user input → textarea → in-memory state | Untrusted free text; must survive timer expiry and autosave failures |
| in-memory state → localStorage (fluentpath.celpip.v1) | Client-owned persistence; setItem can throw (quota/private mode) |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-04 | Denial of Service | Autosave localStorage.setItem | medium | mitigate | Wrap setItem in try/catch that surfaces the warning copy and preserves in-memory text — quota-exceeded never crashes or silently drops the draft |
| T-01-05 | Tampering | Timer expiry path | high | mitigate | Expiry locks the editor but never clears state; Continue untimed only sets outOfTime and re-enables editing — no code path discards learner text |
| T-01-02 | Information Disclosure | Rubric/results rendering user text | medium | mitigate | User text and rubric explanations render through JSX text interpolation only; no raw-HTML injection API |
| T-01-SC | Tampering | npm/pip/cargo installs | low | accept | No package installs this phase — no new libraries |
