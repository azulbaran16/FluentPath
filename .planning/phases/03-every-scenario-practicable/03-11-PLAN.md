things this phase made non-theoretical, re-prove the honesty mechanism now that there is real content

looked. This phase adds roughly 550 authored items and around 490 new keys to a live production
database column, and the two claims it makes are exactly the two a passing script cannot establish on
its own: that a due scenario item renders in the review flow, and that a page saying it has practice
actually has it.

last at which anyone will remember why. Plan 01 stopped the scenario page reading the per-world
generic phrase set, and plan 04 gave all thirty-five scenarios curated sets of their own. Every
remaining call site — the five speaking packs in the phrase module and the three in the global
speaking page — passes a curated key and always did, so the fallback branch is already dead code.

first one authored without a phrase set would quietly be served another scenario's, which is exactly
the failure this phase exists to remove. Five lines go, and the strict accessor becomes the only one.

Output: a green suite with recorded totals, a measured payload, a re-proved control, one dead
