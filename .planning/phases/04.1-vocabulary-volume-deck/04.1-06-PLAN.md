<ordering_correction added="2026-08-04" applies_to="this plan and 04.1-05, 04.1-06">
## Run the near-duplicate scan BEFORE regenerating the fixture

As written, Task 1's verify runs `verify-id-stability.mts --update` and Task 2 then scans for
near-duplicates and **rewrites cards**. That order is wrong and it contradicts this phase's own
rule: content is not final until the scan has run, so regenerating in Task 1 either bakes in a
hash you are about to invalidate or invites a second `--update` to launder it.

**"Twice is fine because it is uncommitted" is exactly the habit 04-07 came from.** Plan 03 hit
this, inverted the order, and regenerated once; do the same here.

**Correct order:** author the cards → run the near-duplicate scan and make every rewrite → *then*
`--update`, **once** → commit content and fixture together, atomically. Task 1's `--update` verify
becomes an idempotence check that runs after the scan, which is the only point at which it can
pass.
</ordering_correction>

<cognate_decision added="2026-08-05" decided_by="user" applies_to="04.1-05, 04.1-06 and any later batch">
## `cognate` is a declared skip reason — use it, do not gloss around it

The gate asserts `es !== word`. The NGSL contains words that are **identical in Spanish**:
`total`, `natural`, `general`, `personal`, `similar`, and others below rank 500.

**Decision (user, 2026-08-05): declare `cognate` in the skip register's closed vocabulary and
skip them.** A Spanish speaker does not need a flashcard to learn that *total* is *total*; a card
there teaches nothing and only exists to satisfy a rank. Rank completeness stays derived and total
because the register absorbs them, which is exactly what the register is for.

This follows the pattern `already-taught` set: declared at plan 01 with zero entries, first used at
plan 03. Declare `cognate` with its reason text **before** the first batch that needs it.

**Where the line is.** `cognate` means *no honest Spanish gloss differs from the English word*. It
is NOT for a word that merely looks similar and has a real gloss — `local` → "del barrio / de la
zona", `real` → "auténtico / de verdad", `idea` → "ocurrencia" were all glossed honestly and stay
carded. If a natural synonym exists, card it; if forcing one would produce a slash-fudge, skip it.

**One repair is owed, and it is a retirement, not an edit.** `vocab:color` shipped in plan 04
glossed `"color / tono"` — it passes the gate and is a fudge of exactly the kind this decision
exists to stop. Under `AGENTS.md` a live id's content may never be rewritten, so the fix is:
declare `color` retired in the fixture **by hand, with a reason, before `--update` runs**, remove
the card, and add `color` to the skip register as `cognate`. Do not edit the card in place.
</cognate_decision>
