<objective>
The gate. Sounding Native now carries roughly three times the material it did, one scenario has been
re-selected rather than extended, the recall deck has a new component behind it and the phase has
added several assertions that have never failed. Each of those is a claim, and this plan is where
each becomes evidence or stays open by name.

Three things this phase cannot prove from a script, in order of how easily they are skipped:

1. **A new assertion that cannot fail is decoration.** Every gate this phase added — batching,
   id stability, the tips, the pairing, the shelf life, the session length, the payload — gets a
   mutation aimed at it and must be caught on its own label.
2. **The harness sees byte-identity, and a lazy paraphrase passes everything.** With well over a
   hundred items authored across seven plans by an agent that could not see the others' output, this
   is the phase where near-duplication is likeliest in the project's history. The reader pass is the
   only defence, and Phase 3 measured the baselines it has to beat.
3. **The batched deck has never been seen.** It is the one component change in the phase, it sits
   between the learner and every recall item in the app, and its rest point, its counter and its
   completion totals are exactly the kind of thing that is correct in a pure function and wrong on a
   page.

**If execution stops inside this plan**, the content is already shipped and honest — coverage is
derived throughout — and what is missing is the evidence, which the plan records as missing rather
than as done.

Purpose: turn the phase's claims into evidence, and close CONT-04 only on what was earned.
Output: a measured gate, a reader pass, a browser pass, and an auditable requirement.
</objective>

- an existing scheduled id given different content behind it — the re-point the whole phase is
  guarding against;
- a retired id put back into a bank;
- a deck chunked by hand in the component rather than through the one author;
- a batch produced above the ceiling, and a batch order permuted;
- a scenario's advertised minutes left behind after its bank grew;

driver rather than the gates.

changed, the expected label in the output, and a file that still parses; a non-zero exit from a
syntax error is not a catch, and an unchanged file reporting SURVIVED is a fabricated gap. Both of
those have happened in this repo and both were caught by requiring evidence rather than reading an
exit code.
